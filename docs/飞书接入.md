# 飞书机器人接入指南

把知识库问答接进飞书:群里 **@机器人** 或 **私聊机器人** 问运营问题,机器人回带引用的卡片。

## 原理

| 方向 | 走什么 |
|---|---|
| 收消息 | 自建应用「事件订阅」`im.message.receive_v1` → POST `/api/feishu/webhook` |
| 回消息 | 应用 `tenant_access_token` + `im/v1/messages` 发卡片/文本 |

飞书事件订阅需要一个**公网回调地址**(飞书服务器回调你的服务)。本地用 **Cloudflare Quick Tunnel**(cloudflared)开隧道实现 —— 免费、无需域名、无需登录。

## 步骤

### 1. 建自建应用(飞书开放平台)

1. 打开 https://open.feishu.cn/app  → **创建企业自建应用**
2. 应用名称写「知识库客服」(或任意),创建后进「凭证与基础信息」记下 **App ID / App Secret**
3. 「事件与回调」→ 订阅方式选 **将事件发送至开发者服务器** →
   - **请求地址 URL**:先留空,等隧道起来再填
   - **Encrypt Key**:留空
   - **Verification Token**:点「生成」复制
4. 「权限管理」开通:
   - `im:message`(以应用身份发消息)
   - `im:message.group_at_msg` 或 `im:message.p2p_msg`(接收群聊/单聊消息,按平台提示开)
5. 「事件与回调」→ **订阅事件** → 添加 `接收消息 im.message.receive_v1`

### 2. 填配置

```bash
# config/feishu.local.json(不入库)
{
  "app_id": "cli_xxx",
  "app_secret": "xxx",
  "verification_token": "xxx",
  "encrypt_key": "",
  "bot_name": "知识库客服"
}
```

### 3. 装 cloudflared(只需一次)

```bash
# 已装到 D:/d/cloudflared/cloudflared.exe(winget install cloudflare.cloudflared)
# 检查:
D:/d/cloudflared/cloudflared.exe --version
```

### 4. 一键启动 + 拿回调地址

```bash
# 方式一(推荐):双击根目录「一键启动飞书隧道.bat」
# 方式二:命令行
python scripts/launcher.py --tunnel
```

脚本自动:拉起 :8000 服务 → 拉起 cloudflared Quick Tunnel → **打印事件订阅回调地址**,例如:

```
事件订阅回调地址(复制去飞书后台粘贴):

      https://struck-gazette-groups-processes.trycloudflare.com/api/feishu/webhook
```

把上面这个地址填回第 1 步的「请求地址 URL」,点保存 —— 飞书会发 `url_verification` 握手,我们的接口自动回 `challenge`,验证通过。

### 5. 测试

1. 把机器人加进一个群(或直接在应用后台「使用机器人」添加)
2. 群里 **@机器人** 问「变体值最多能填多少字符?」→ 机器人回卡片
3. 私聊机器人也可以
4. 问「折叠刀能不能上」→ 机器人回红色卡片:⛔ banned 命中折叠刀

## 常见问题

- **保存回调地址失败**:说明隧道没通。看 `data/cloudflared.log` 有没有报错;确认能访问外网(Quick Tunnel 需要连 Cloudflare)。
- **机器人不回群消息**:只回 **@了机器人** 或 **私聊** 的消息(避免刷屏)。群聊里必须 @ 它。
- **本地调试跳过签名**:`set ALLOW_UNVERIFIED=1` 后重启(仅本地,生产别开)。
- **卡发不出去**:看 `data/server.log` 的 token 报错 —— 多半是权限没开或 App Secret 填错。
- **地址变了 / 隧道断了**:Quick Tunnel 是随机地址,每次重启都会变。**重新双击 bat,以它打印的地址为准**,再回飞书后台更新回调地址。要固定地址需用 Cloudflare 账号 + 域名做正式 Tunnel。

## 也可以不接飞书

只想要"能直接对接平台的 API":在 `config/app.json` 配

```json
{ "api_token": "一串随机密钥" }
```

然后 `python scripts/launcher.py --lan`(绑定 0.0.0.0),任何系统调
`POST http://<IP>:8000/api/ask` + 头 `X-Api-Key: 那串密钥` 即可。接口文档看
`http://<IP>:8000/docs`(Swagger)。
